# 吱熊猫 ZhiPanda 前端设计政策

- **状态：** 当前生效的前端品牌、真实性与交付政策（视觉规则见设计系统）
- **生效日期：** 2026-07-25，2026-10-23 改为引用设计系统
- **适用范围：** `apps/web` 的公开页面、共享组件、视觉样式、文案与前端测试
- **设计系统：** `zhipanda-design-system.md` 定义视觉、排版和组件
- **品牌与文案合同：** `zhipanda-public-brand-and-copy-contract.md` 定义公开命名边界与双语语气

## 1. 项目定义

中文品牌名为 **吱熊猫**，英文品牌名为 **ZhiPanda**。

吱熊猫是一个主要面向熊猫爱好者的现代熊猫信息网站。用户应当能够从真实熊猫图片和名字开始，快速了解个体资料、家庭关系、生活地点、时间线与公开来源，并自然地继续探索其他熊猫。

产品首先是一套亲近、现代、图片驱动的公众体验；可信数据、来源、许可和修订能力是它的基础，而不是压过熊猫内容的视觉主题。

## 2. 视觉规则

公开页面的颜色、字号、间距、圆角、组件写法和十条设计规则，统一写在 `zhipanda-design-system.md`。本文不再规定视觉风格，只保留真实性、图片和交付要求。

## 3. 规则优先级

发生冲突时，按以下顺序处理：

1. 真实性与媒体许可、隐私、安全和领域事实；
2. 无障碍与核心任务可完成性；
3. `zhipanda-design-system.md` 定义的设计系统；
4. 本文其余规则。

不得为了视觉完整度使用其他熊猫图片、AI 生成个体照片、随机图片服务或来源不明媒体。

## 4. 图片规则

### 首页

- 首屏采用“搜索 + 一张授权熊猫主图”的非对称双栏布局；
- 主图必须链接到具体熊猫资料页；
- 搜索入口在首屏内保持明确，不得被图片推到下一屏。

### 个体熊猫

- 有授权媒体时，选择 `primary` 媒体作为首屏视觉中心；
- 桌面采用图片与身份资料双栏，移动端采用上图下信息；
- 图片不承载大段覆盖文字，不叠放装饰性状态徽章；
- 页面下方媒体区可以继续展示完整图库和许可记录。

### 无图或加载失败

- 保留与主图相同的稳定布局；
- 用一句短话说明暂无照片或照片加载失败；
- 不使用其他熊猫或通用图片替代；
- 文字资料、家人和生活过的地方仍须完整可用。

## 5. 文案规则

公开文案优先使用熊猫爱好者能直接理解的语言，词表见 `zhipanda-design-system.md` 第 7 节。不加解释性说明文字；不把推测写成熊猫性格；不过度卖萌，不用行政数据库语气。

## 6. 每个前端 PR 的完成条件

1. 对照 `zhipanda-design-system.md` 第 9 节完成设计自检；
2. 运行 `npm run check:design-policy -w apps/web`；
3. 运行架构检查、lint 和 typecheck；
4. UI 可见变更提供中英文桌面与移动截图，直接附在 PR 正文或评论中，并列出已覆盖的状态和 axe 结果；`.release-gate/` 只作本地工作目录，证据以 PR 上可见的内容为准；
5. 验证键盘、焦点、减少动画、无 JavaScript 核心路径；
6. 验证有图、无图、加载失败、部分数据和长文本状态；
7. 不修改或覆盖并行的数据采集工作。
