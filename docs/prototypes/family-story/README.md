# Family Story prototype package

Review artifacts for Wayfinder issue #233.

- `smithsonian.html`: `programme_longform_v1`, a multigenerational, media-limited Smithsonian family story with seven core members, nine confirmed scoped relationships, one scoped tentative dependency, and an explicit exclusion of Tian Tian's two tentative ancestor dependencies.
- `ueno.html`: `twin_parallel_v1`, a compact Ueno twin-family story where all four members have licensed media and the family-level sequence deliberately features the parents.
- `prototype.css`: shared responsive visual language.
- `screenshots/`: desktop and mobile renders.

Data is based on public release `2026.07.24.2` and clearly labelled design behavior. These are decision artifacts, not production code.
