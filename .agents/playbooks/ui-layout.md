### PandaAtlas: UI layout changes

- **Before** "Delegate code-writing to a subagent" Draw a mockup of the changed screen first, with real data, and show it to the user. Write no layout code until the user approves the mockup. Put icons directly on the surface, never inside a tinted square or circle.
